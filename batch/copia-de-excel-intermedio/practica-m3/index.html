🔎 Ejercicio 1: Filtrado de lista de estudiantes

Tienes una lista de estudiantes con los campos Nombre, Edad, Género y Calificación. Practica el uso de filtros para obtener información específica.
  • Usa los autofiltros sobre cada encabezado para mostrar solo las filas que cumplen.
  • Observa la tabla filtrada y responde los 3 requerimientos del panel inferior.
  • Escribe el número que leíste (también aceptamos una fórmula tipo =PROMEDIO(...)).
–
≥
Nombre Edad▾ Género▾ Calificación▾
Ningún estudiante cumple los criterios de filtro actuales.
Panel de respuestas — filtra, lee el resultado y escríbelo (Enter para evaluar)
💡 Para el Req 1 filtra Edad de 18 a 25; para el Req 2 elige Género = Femenino; para el Req 3 pon Calificación ≥ 90. Los promedios van redondeados a 2 decimales.

✅ Ejercicio 2: Validación de datos

Creas una hoja para que los empleados registren gastos de viaje. Establece reglas de validación y prueba ingresar valores inválidos para ver cómo la validación los rechaza.
①Fecha dentro del último mes: del 2026-05-13 al 2026-06-13.
②Monto mayor que cero.
③Categoría desde una lista: Transporte, Hospedaje, Comida.
④Aprobado solo Sí o No.
Fecha Concepto Monto Categoría Aprobado
Las celdas se validan en vivo: válida · inválida (muestra el motivo del rechazo).
💡 En Excel real esto se configura en Datos → Validación de datos: rango de fecha, número mayor que 0, y listas desplegables. Aquí las reglas ya están activas: intenta romperlas.
