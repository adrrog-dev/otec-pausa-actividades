P1 — Trazar la ejecución de un procedimiento VBA

Ejecuta mentalmente el siguiente código y determina el valor de resultado al finalizar:

Sub Calcular()
    Dim resultado As Long
    Dim i As Integer
    resultado = 1
    For i = 1 To 5
        If i Mod 2 = 0 Then
            resultado = resultado * i
        End If
    Next i
    MsgBox resultado
End Sub
